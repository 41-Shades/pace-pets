# User Experience Map

Status: reference.

Compact map of the public extension's user-facing interactions and experiences.
Paths use `→`, stay within three steps, and exclude local developer controls.

## Tier 1 — Primary

Core paths that deliver Pace Pets' main value.

- **See pace at a glance:** View the toolbar badge → read pace or a critical-window alert.
- **Open the dashboard:** Select the Pace Pets toolbar icon → view current pace, usage, time, burnout, reset timing, and history.
- **Complete the first check:** Open the dashboard → select **Check now** → grant optional ChatGPT site access.
- **Refresh actionable usage:** Open the dashboard or toolbar context menu → select **Check now** or **Check usage now** → view the updated status.
- **Inspect history:** Open the dashboard → hover or touch the chart → read the nearest timestamp, usage, time, and pace values.
- **Switch usage window:** Open the dashboard → select the window control or press `T` → view another available window.

## Tier 2 — Secondary

Supporting preferences, context, and local-data controls.

- **Choose the toolbar badge window:** Right-click the toolbar icon → select an available badge window.
- **Change theme:** Open the dashboard → select the theme control.
- **Change motion:** Open the dashboard → turn motion effects on or off.
- **Change sound:** Open the dashboard → enable, mute, or adjust dashboard audio.
- **Understand burnout:** Open the dashboard → hover or focus **Burnout** → read its meaning.
- **Read product information:** Open the dashboard → select **About Pace Pets** → read product, privacy, affiliation, and source details.
- **Clear local data:** Open **About Pace Pets** → select **Clear data** → return to the reset dashboard state.
- **Open a product link:** Open **About Pace Pets** → select 41 Shades, Chrome Web Store, or GitHub.

## Tier 3 — Other

Alternate, playful, passive, and rare experiences.

- **Use toolbar shortcuts:** Right-click the toolbar icon → open Pace Pets, check usage, or choose the badge window.
- **Dismiss transient UI:** Press `Esc` → close the info panel, early-reset response, or tooltip.
- **Try early reset:** Open the dashboard → select `!!` → receive the playful no-op response.
- **Scan the pace catalog:** Open the dashboard → view the passive state rail → find the highlighted current state.
- **See a pace-state effect:** Open or leave the dashboard visible → enter a pace level → see its matching card, icon, and motion treatment.
- **See an imperfect-state effect:** Open or leave the dashboard visible → reach **Splat!** or **Nothingness** → see its matching presentation.
- **See a perfect-state experience:** Open or leave the dashboard visible → reach **Big Bang**, **Perfect sync**, **Perfect zero**, or **Singularity** → see its matching special presentation.

Pace Pets offers only the usage windows reported by the signed-in account's
latest successful check. A newly reported window becomes available without
changing the current selection; a selected window that disappears falls back
to the remaining available window.
