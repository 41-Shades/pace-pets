Quick Start

  1. Install Pace Pets from the Chrome Web Store.
  2. Click the Pace Pets toolbar icon.
  3. For source installs, load collector/extension as an unpacked extension from chrome://extensions.

Chrome Extension

The extension uses the existing signed-in ChatGPT browser session, normalizes supported usage windows, and stores only safe history fields in chrome.storage.local. The extension page is the product UI.

Public listing: Pace Pets on the Chrome Web Store.

Dashboard Behavior

The dashboard shows weekly and five-hour reset windows, current pace, remaining usage/time percentages, reset timing, a local Chart.js pace chart, and pace legend chips that can preview mock pace states. No local web server is required.

Important Paths

  • collector/extension: unpacked Chrome extension.
  • collector/extension/dashboard.html: extension dashboard page opened from the toolbar action.
  • collector/extension/history-store.js: bounded extension-local history store.
  • collector/extension/vendor/chart.umd.min.js: vendored Chart.js runtime asset.
  • scripts/package-extension.mjs: release zip, metadata, and checksum generator for the packaged extension.
  • data/usage.sample.json: safe sample fixture.
