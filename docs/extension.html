Extension Setup

The local Chrome extension reads the ChatGPT/Codex usage endpoint with your existing signed-in browser session, stores bounded safe history in extension-local storage, and renders the Pace Pets dashboard.

Install

  1. Open chrome://extensions.
  2. Enable Developer Mode.
  3. Click Load unpacked.
  4. Select the collector/extension folder from this project.
  5. Click the Pace Pets toolbar icon to open the dashboard.

Refresh Behavior

  • Refreshes every five minutes from the background worker.
  • The first scheduled refresh runs shortly after install/startup.
  • If the toolbar badge shows !, confirm Chrome is signed in to ChatGPT and reload the unpacked extension if needed.
  • Right-click the toolbar icon to choose whether the badge shows the 7d or 5h view.

Stored Data

The extension stores only normalized usage history in chrome.storage.local.

The generated storage schema reference is maintained from the runtime storage contracts and sample fixture in docs/reference/storage-schema.md.

  • Cookies and browser session state remain in Chrome.
  • The extension may read a ChatGPT session token in memory during refresh, but it does not persist or log it.
  • No cookies, tokens, raw responses, account IDs, raw page text, or raw HTML are stored locally.
  • History is bounded to 14 days or 500 samples, whichever is smaller.
  • The collector uses an undocumented ChatGPT web endpoint and may need maintenance if that endpoint or response shape changes.

Custom Icons

Replace PNG files under collector/extension/themes/default/ to customize the local extension artwork. Keep the existing filenames for a no-code swap, then reload the unpacked extension from chrome://extensions.

The theme asset mapping lives in collector/extension/themes/default/asset-manifest.js. App icon paths also have to stay aligned with collector/extension/manifest.json because Chrome reads them directly from its extension manifest.

Chart Asset

Chart.js is loaded from collector/extension/vendor/chart.umd.min.js. After changing the pinned package version, run npm run vendor:chart to refresh the vendored browser bundle.
